 LUFWANYAMA DISTRICT TELEMEDICINE SYSTEM — HOW TO RUN
============================================================

QUICK START (recommended)
--------------------------
1. Double-click  start.bat  in this folder.
   That's it. The script will:
     • Start the MySQL database server if it is not already running
     • Start the PHP web server on http://localhost:8000
     • Open your browser to the login page automatically

2. When you are done, double-click  stop.bat  to shut everything down cleanly.

-----------------------

  start.bat starts it automatically, and falls back to
  C:\Program Files\MySQL\MySQL Server*\bin or C:\xampp\mysql\bin
• The database "telemedicine" is created with all six tables
• No demo patients or appointments: the records start empty

MANUAL START (if start.bat does not work)
-----------------------------------------
Open a Command Prompt (cmd.exe) and run these two commands:

  Step 1 — start the MySQL server:
    "C:\mysql\bin\mysqld.exe" --defaults-file="C:\mysql\my.ini"

  Step 2 — open a second Command Prompt and start the web server:
    cd "C:\emmy project"
    php -S localhost:8000 router.php

  Step 3 — open your browser to:
    http://localhost:8000


STOPPING THE SERVER
--------------------
• Double-click stop.bat, OR
• Press Ctrl+C in the PHP server window, then run:
    "C:\mysql\bin\mysqladmin.exe" -u root shutdown


TROUBLESHOOTING
---------------
"Database connection failed"
  → The MySQL server is not running. Double-click start.bat again, or start
    with the command in MANUAL START above.

"Can't connect" / port 3306 already in use
  → XAMPP also ships a database server on port 3306. Only one server can
    use the port, so stop MySQL in the XAMPP Control Panel before running
    start.bat (this project uses the MySQL at C:\mysql).

"could not find driver"
  → pdo_mysql is not enabled. Open C:\php\php.ini, search for "pdo_mysql",
    remove the semicolon at the start of the line, save, and restart the server.

Blank white page
  → Open config\config.local.php and set:
      $APP_ENV = 'development';
    Then reload to see the real error message.

"Invalid or expired request" after submitting
  → Your session timed out. Reload the page and submit again.

Login always fails
  → Make sure there are no spaces in the phone number.
  → Make sure an account exists. If the database is empty, run:
      php tools/install.php        (creates the administrator)
      php tools/demo_accounts.php  (one account per role)

Port 8000 already in use
  → Another program is using that port. Edit start.bat and change 8000 to 8080
    (two places: the php -S line and the start "" http:// line).
